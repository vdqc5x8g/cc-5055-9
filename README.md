# 镜面合成 · 镜头跟踪窗口

面向影视合成的**平面镜几何工具**。它从一帧里同时可见的**直接标记**与**镜中反射**
出发，依据已知场景约束真实解算相机—镜面关系，使插入的虚拟物体与它的镜中像
在几何上正确对应；并对反射位置、镜面方向、接触位置做量化核对。

> 关键原则：镜中像是**虚拟相机**（反射形成的、手性为负的独立相机）的投影，
> 工具从不把镜中像当作现实中另一组“同位置标记”参与普通位姿估计，也**从不**把
> 虚拟物体画面水平翻转贴进镜区来冒充空间关系正确。

## 图形入口（推荐的交互方式）

镜面合成的主界面是一个镜头跟踪窗口，直接在浏览器打开即可：

```bash
npm start
# 打开 http://localhost:4173/
```

窗口包含：

- **视图区**：合成视图 / 相机视图 / 俯视图切换；可开关**光线路径**、直接射线、
  镜面射线与真值轮廓；点击标记可查看“相机→标记”与“相机→镜面命中点→标记”
  两条光路，以及虚拟相机一侧的虚像射线。
- **镜面约束**：面板中心、yaw/tilt、尺寸可调；“求解镜面合成”在此窗口内完成，
  无需命令行。
- **求解选项**：固定焦距、观测噪声 σ、**直接缺失比例**滑块（模拟标板被遮挡）、
  联合精化开关。
- **虚拟物体**：在地面 (y=0) 上指定接触点与偏航。
- **结果区**：求解结果与真值评分、**反射位置与几何误差**逐点表、手性/深度分支
  对比与诊断（异常在此提示）、以及**采用的约束**清单。

页面底部同时给出了该图形入口与命令行辅助的说明。

## 多段标定编辑器（可移动镜面）

第二个图形入口面向**镜面会在拍摄中途换位**的镜头：相机锁定不动，镜面在不同
区段取不同姿态，每个区段各自标定，全部区段共享同一个**锁定的镜框**（面板尺寸
+ 面内锚点）。

```bash
npm start
# 打开 http://localhost:4173/segments.html
```

编辑器包含：

- **时间线**：两个活动区段（可拖动中段边界，帧立即重新指回各自区段的相机与
  镜面状态）、播放头、演员遮挡/手性干扰/右侧出画的事件底纹、镜面换位刻度与
  逐帧**折角**条。
- **两侧分别录入**：左/右标板观测分开录入（可单帧单侧补录），角点标记作为
  共享镜框证据；同位置但**手性相反**的干扰标记（位于镜面背面的直接内容）被
  几何判据隔离，绝不进入反射求解。
- **区段卡片**：状态（正常/过期/失效/求解不足）、证据帧与两侧证据区间、
  **单独重估**（不动其它区段）、失效模拟（仅隔离依赖该区段的合成层）、
  **拖回恢复**（恢复前核对反射方向：虚拟相机 det=−1、相机与标记均在正面、
  反射 RMS 不超限）、在播放头处分裂区段。
- **求解 · 衔接分段解 / 联合拟合对照**：两种实现在相同观测上运行并列表比较
  （法线/面距/面板中心误差、共享锚误差）。干净数据上两者相当；但联合拟合把
  全部区段耦合进同一目标，一段观测被污染时误差会摊进共享锚、扭曲其它区段的
  面板位置，因此**选定共享镜框锚衔接的分段解**——锚由角点观测逐帧估计（逐分量
  中位数），失效隔离在出事的区段内，且每个区段都可单独重估。
- **穿框直线折角检测**：标定直轨与玻璃在面板内接触，直接像与反射像必须相接。
  一侧标记出画后继续改变镜面角度时，缺观测的一侧若沿用过期标定，直线在镜框处
  出现折角（夹角 > 1.5° 或偏移 > 3 px），工具据此**定位到那次编辑**并给出
  补救（分裂区段 + 单独重估）。
- **保存/载入工程**：localStorage + JSON 文件；载入后**从两侧拖回同一帧**量取
  的虚像误差与保存时完全一致（本段 < 1.5 px，对侧即镜面换位的可测特征）。

对应的命令行自检（与窗口同源，非主要交互方式）：

```bash
npm run segments   # 逐项核对：两侧录入、衔接 vs 联合对照、边界拖动、隔离与拖回、
                   # 保存/载入、虚像误差、折角定位与补救
```

## 命令行（仅辅助）

命令行只是同一套 `src/core` 管线的无界面入口，用于批量自检与打印误差，
**不是**主要交互方式：

```bash
npm run verify                      # 用默认场景与预设约束求解并打印误差
node scripts/cli.mjs --constraint none   # 不给面板约束，仅由反射解平面
node scripts/cli.mjs --missing 0.8       # 直接标记缺失 80%，靠镜面增广求相机
node scripts/cli.mjs --screen 794,1225   # 在给定屏幕点按地面约束放置虚拟物体
node scripts/cli.mjs --all --json        # 全部反射点 + 机器可读 JSON
```

`npm run verify` 打印的内容与窗口结果区同源：相机来源、C/f/RMS、镜面法线/平面距、
面板位置来源、反射 RMS、虚拟相机 det、采用的约束、手性/深度分支对比、逐点反射
位置与命中点、镜面完整性核对、真值评分（合成片段）与诊断。

## 生成的镜面真值片段

```bash
npm run clips
```

在 `clips/` 下生成两组带真值的合成片段（PNG 画面 + 每帧真值 `manifest.json`）：

- `mirror-arc-*`：镜面面板沿 X 平移并偏航，部分反射移出有限面板 → 这些点被剔除，
  不再作为有效观测。
- `missing-direct-*`：直接标板从第 3 帧起被遮挡，仅剩地面/台座直接标记，工具用
  镜面约束把镜中观测反射为直接证据来增广相机求解。

每帧有两个文件：`<clip>-NN.png` 为“拍摄画面”（含直接标记与镜中反射），
`check-<clip>-NN.png` 为用**解算结果**叠加的核对图（绿色 = 预测反射位置与解算面板
轮廓，黄线 = 观测与预测偏差，圆形 = 真值接触点，十字 = 解算接触点）。
生成器本身会逐帧检查投影误差、镜面方向、接触位置、无效反射是否被误用，任一帧
不达标即以非零码退出。

`manifest.json` 记录每帧的相机/镜面真值、每个标记的真值像素（直接与反射）、
是否落在镜内、解算结果、误差与采用的约束。

## 几何与算法要点

- **相机模型**：针孔相机（x 右、y 下、z 前），内参 K（像素焦距、主点），
  外参 R|C。DLT（Hartley 归一化）给初值，RQ 分解取 K、R，再用 LM 精化。
- **镜面反射**：S = I − 2nnᵀ；点反射 `X' = X − 2(n·(X−c))n`。
- **虚拟相机**：`C_v = reflect(C)`，`R_v = R·S`（det = −1，非正常手性）。它满足
  `project(virtual, X) = project(real, reflect(X))`（像素误差 < 1e−9）。
- **平面可观性**：反射观测只约束镜面**平面**（n、d），**面板在平面内的横向位置
  不可观测**；它必须来自场景约束，或以反射命中点质心作有限面板的放置依据，并在
  结果区明确标注来源。
- **相机增广**：直接标记太少或共面时，已知镜面约束可把镜中观测反射成对真实相机
  的有效直接观测（`X → reflect(X)`），补齐离面证据；这是五自由度增广，不是把
  镜中像当同位置标记。
- **分支判别**：手性（det=−1 的正确反射 vs 强制 det=+1 的“水平翻转”）、把镜中点
  当直接标记的错误模型、以及镜面深度 ×0.75/×1.25 候选，全部用重投影 RMS 打分，
  正确分支应显著最优。
- **镜面范围/可见性**：反射命中点必须落在有限面板内且相机与物体同处反射正面；
  落在镜外或越出画面的点会带原因被剔除，绝不进入解算。
- **尺度与绝对距离**：缺少镜面位置/尺度约束时，只报告法线与平面距，并按场景单位
  标注绝对距离“仅供参考”，不给出无依据的绝对距离。

## 目录

```
index.html            图形入口（镜头跟踪窗口）
segments.html         图形入口（可移动镜面多段标定编辑器）
styles.css
src/core/             纯计算核心（浏览器与 CLI 共用）
  camera.js dlt.js linalg.js math.js optimize.js
  mirror.js scene.js solver.js branches.js asset.js composite.js pipeline.js render.js
  timelineScene.js    可移动镜面多段镜头（换位/遮挡/手性干扰/出画事件）
  segments.js         多段标定工程：两侧录入、衔接/联合求解、隔离、折角定位、存取
src/ui/main.js        窗口交互与绘制
src/ui/segments.js    多段标定编辑器交互与绘制
scripts/serve.mjs     静态服务器（npm start）
scripts/cli.mjs       命令行辅助（npm run verify）
scripts/segments-cli.mjs  多段标定命令行自检（npm run segments）
scripts/clips.mjs     镜面真值片段生成与自检（npm run clips）
scripts/png.mjs       无依赖 PNG 编码
scripts/raster.mjs    无依赖软件光栅器
tests/                node --test 单元测试（npm test）
clips/                生成的片段与 manifest（npm run clips 后产生）
```
